# Arquimedes

Uma aplicação educativa interativa construída com Streamlit, preparada para desktop e tablet.

## Executar localmente

```powershell
C:/Python314/python.exe -m pip install -r requirements.txt
C:/Python314/python.exe -m streamlit run app.py
```

## Estrutura

- `app.py`: composição principal da interface
- `views/`: páginas independentes
- `components/`: componentes visuais reutilizáveis
- `assets/`: imagens e vídeos do projeto
- `services/`: integrações futuras, como Supabase
